# Roblox Lua Integration Guide

## Overview
This key generation system provides a REST API that your Roblox game can use to verify keys generated by players.

## API Endpoint

**Verify Key Endpoint:**
\`\`\`
POST https://your-domain.vercel.app/api/verify-key
\`\`\`

## Roblox Lua Example

\`\`\`lua
local HttpService = game:GetService("HttpService")

-- Your deployed website URL
local API_URL = "https://your-domain.vercel.app/api/verify-key"

function verifyKey(playerKey)
    local success, result = pcall(function()
        local response = HttpService:PostAsync(
            API_URL,
            HttpService:JSONEncode({
                key = playerKey
            }),
            Enum.HttpContentType.ApplicationJson,
            false
        )
        
        return HttpService:JSONDecode(response)
    end)
    
    if success and result.valid then
        return true, result
    else
        return false, result
    end
end

-- Usage example
local playerInputKey = "ABCD-1234-EFGH-5678"
local isValid, data = verifyKey(playerInputKey)

if isValid then
    print("Key is valid!")
    print("User ID:", data.userId)
    print("Expires at:", data.expiresAt)
    -- Grant access to premium features
else
    print("Invalid or expired key")
    -- Deny access
end
\`\`\`

## Setup Steps

1. Deploy your website to Vercel
2. Enable HTTP requests in your Roblox game (Game Settings > Security > Enable Studio Access to API Services)
3. Replace `your-domain.vercel.app` with your actual deployment URL
4. Use the verification function in your game's scripts

## API Response Format

**Valid Key:**
\`\`\`json
{
  "valid": true,
  "userId": "uuid-here",
  "expiresAt": 1234567890
}
\`\`\`

**Invalid Key:**
\`\`\`json
{
  "valid": false,
  "error": "Invalid or expired key"
}
\`\`\`

## Security Notes

- Keys expire after 1 hour
- Each user can only generate 2 keys maximum
- 30-second cooldown between key generations
- User tracking prevents abuse through page refreshes
